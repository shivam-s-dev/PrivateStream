## Data Types

### `Dataset`
Stored persistently keyed by `DataKey::Dataset(id)`.

| Field | Type | Description |
|---|---|---|
| `id` | `u64` | Auto-incremented unique identifier |
| `provider` | `Address` | Stellar address of the data provider |
| `title` | `String` | Human-readable dataset name |
| `category` | `u32` | Category code (1=Finance, 2=IoT, 3=AI, etc.) |
| `price_per_second` | `i128` | Cost in USDC stroops per second (7 decimals) |
| `endpoint_hash` | `String` | SHA-256 hash of the data endpoint URL |
| `is_active` | `bool` | Whether the dataset is currently accepting sessions |
| `total_earned` | `i128` | Cumulative USDC earned (in stroops) |
| `session_count` | `u32` | Total number of settled sessions |

### `Session`
Stored persistently keyed by `DataKey::Session(id)`.

| Field | Type | Description |
|---|---|---|
| `id` | `String` | Unique session identifier (e.g., `SESS_1234567890`) |
| `dataset_id` | `u64` | Reference to the consumed dataset |
| `consumer` | `Address` | Buyer's Stellar address |
| `provider` | `Address` | Provider's Stellar address |
| `budget` | `i128` | Locked USDC amount in stroops |
| `price_per_second` | `i128` | Locked-in rate at session open time |
| `opened_at` | `u64` | Ledger timestamp when session was opened |
| `status` | `SessionStatus` | One of: `Active`, `Settled`, `Disputed` |

### `SessionStatus`
```rust
pub enum SessionStatus {
    Active,    // Funds locked, streaming in progress
    Settled,   // Provider paid, refund issued
    Disputed,  // Timeout: full refund issued to consumer
}
```

## Functions

### `initialize`

Sets up the contract for first use. Can only be called once.

**Auth:** None required (permissionless bootstrap)

```rust
pub fn initialize(
    env: Env,
    usdc_token: Address,   // USDC SAC address on this network
    fee_collector: Address, // Platform wallet to receive fees
    fee_rate_bps: u32,     // Fee in basis points (50 = 0.5%)
)
```

**SDK Call:**
```typescript
contract.call('initialize', 
  nativeToScVal(usdcAddress, { type: 'address' }),
  nativeToScVal(feeCollector, { type: 'address' }),
  nativeToScVal(50, { type: 'u32' })
)
```

### `register_dataset`

Registers a new dataset on-chain. The provider's wallet must sign.

**Auth:** `provider.require_auth()`  
**Returns:** `u64` — the new dataset ID

```rust
pub fn register_dataset(
    env: Env,
    provider: Address,
    title: String,
    category: u32,
    price_per_second: i128,  // in USDC stroops
    endpoint_hash: String,   // SHA-256 of the endpoint URL
) -> u64
```

**Events emitted:** `REGISTER`

### `open_session`

Locks a consumer's USDC budget into the contract escrow and creates an on-chain session record. Requires the consumer to sign.

**Auth:** `consumer.require_auth()`  
**Transfers:** `budget` stroops from `consumer` → `contract`

> ⚠️ The consumer must have sufficient USDC balance on the Stellar network. The SAC `token.transfer()` will pull funds directly from the consumer's account.

```rust
pub fn open_session(
    env: Env,
    consumer: Address,
    session_id: String,   // Unique ID generated by the client
    dataset_id: u64,      // Must reference an active dataset
    budget: i128,         // USDC stroops to lock in escrow
)
```

**Events emitted:** `OPEN_SESS`

**Reverts if:**
- `session_id` already exists
- `dataset_id` does not exist or `is_active == false`
- `budget <= 0`
- Consumer has insufficient USDC balance

---

### `settle_session`

Distributes escrowed funds: pays the provider for consumed data, refunds the remainder to the consumer, and takes a platform fee. Only callable by the `fee_collector` (backend relayer).

**Auth:** `fee_collector.require_auth()`  
**Transfers:** From contract → provider, fee_collector, and consumer

```rust
pub fn settle_session(
    env: Env,
    session_id: String,
    consumed_amount: i128,  // Actual USDC stroops consumed during the session
)
```

**Settlement math:**
```
fee_amount     = consumed_amount * fee_rate_bps / 10_000
provider_gets  = consumed_amount - fee_amount
consumer_gets  = budget - consumed_amount
```

**Events emitted:** `SETT_SESS`

**Reverts if:**
- Session does not exist or is not `Active`
- `consumed_amount > budget`

---

### `dispute_session`

Allows a consumer to claim a full refund if the provider has not settled within 24 hours (86,400 ledger seconds).

**Auth:** `session.consumer.require_auth()`  
**Transfers:** Full `budget` from contract → consumer

```rust
pub fn dispute_session(env: Env, session_id: String)
```

**Events emitted:** `DISP_SESS`

**Reverts if:**
- Session does not exist or is not `Active`
- Less than 86,400 seconds have elapsed since `opened_at`
- Caller is not the original consumer

## Events

| Symbol | Emitted By | Payload |
|---|---|---|
| `REGISTER` | `register_dataset` | `(dataset_id,)` |
| `OPEN_SESS` | `open_session` | `(session_id, consumer, budget)` |
| `SETT_SESS` | `settle_session` | `(session_id, consumed_amount, provider_amount, refund_amount)` |
| `DISP_SESS` | `dispute_session` | `(session_id, consumer)` |

You can subscribe to these events via the Soroban RPC `getEvents` method using the contract ID as the filter.

## Error Conditions

| Condition | Behavior |
|---|---|
| Dataset not found | `panic!` / contract revert |
| Session already exists | `assert!` fails |
| Session not active | `assert!` fails |
| `consumed_amount > budget` | `assert!` fails |
| Dispute before 24h timeout | `assert!` fails |
| Unauthorized caller | `require_auth()` revert |
| Insufficient consumer balance | SAC `transfer` revert |

## Calling from the SDK

```typescript
import { rpc, Contract, TransactionBuilder, Networks, nativeToScVal } from '@stellar/stellar-sdk'

const sorobanServer = new rpc.Server('https://soroban-testnet.stellar.org')
const contract = new Contract('CDBD72VIJTM4QNV2MR3C3OBRQUHA56PSBFSUJFRHZBYUSUOCQ5TUUNBE')

// Call get_session (read-only simulation)
const tx = new TransactionBuilder(account, { fee: '100', networkPassphrase: Networks.TESTNET })
  .addOperation(contract.call('get_session', nativeToScVal('SESS_1234567890', { type: 'string' })))
  .setTimeout(30)
  .build()

const result = await sorobanServer.simulateTransaction(tx)
```
